🛡️ Vibe Security Attestation

A publishable security check for apps built with AI tools. Free, open, no server, no account. Everything on this page runs in your browser — nothing leaves your device.

Step 1 — Your app

This page makes a self-declared file — your own claim about your app. A verified file is issued by an independent verifier, not by this tab.

Step 2 — Answer the 10 checks

Only answer for your own app. Test each one with read-only requests — never try to break in, and never write or delete data.

Answer all 10 checks to get your file.

Step 3 — Get your file and badge

Publish

    
Upload the file to /.well-known/vibe-security.json on your app's
    domain (most hosts let you add a file to the public folder). Then anyone can read it at
    . The file expires in 90 days — re-check and republish
    before then.

  







  
Check an attestation file

  
Paste a file's contents, or enter an app URL to fetch it from
  /.well-known/vibe-security.json. Fetching only works if the app's server allows
  cross-origin reads — if it fails, paste the file instead.
